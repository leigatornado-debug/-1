# Virtual GPS Test Tool

一个用于 Android 开发与 QA 的模拟位置测试示例：包含摇杆悬浮窗、路线播放和跑步配速输入。仅使用 Android 开发者选项中授权的模拟位置能力；不会隐藏模拟位置标志、绕过应用检测或伪造传感器数据。

## 构建

- Android Studio / JDK 17
- Android SDK 35
- Gradle sync 后运行 `app`

## 使用

1. 在设备开发者选项中选择本应用作为“模拟位置信息应用”。
2. 启动应用并授予精确位置权限。
3. 点击“启动测试定位”。首次启动后如系统提示权限或模拟位置设置，请按提示完成。
4. 需要摇杆时授予悬浮窗权限，再点“显示摇杆悬浮窗”。向上为北、向右为东；松开停止移动。
5. 配速格式为 `分:秒/公里`，例如 `6:00`。路线点格式为 `纬度,经度;纬度,经度`。
6. 点击停止按钮结束服务并移除测试 provider。

只在自己拥有或获准测试的设备和应用中使用。不同 Android 版本和厂商 ROM 的模拟位置支持可能有所不同。
